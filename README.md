# Framingham Motors, Inc.

Framingham Motors storefront for retro and classic collectible vehicles. The public React interface uses the Framingham Motors identity and content; the ASP.NET Core API, SQLite inventory, protected admin workspace, lead forms, finance estimator, transport planner, trade-in requests, and VIP signup remain connected to the existing B & B application backend.

## Local development

Prerequisites: Node.js 20+ and .NET 9 SDK/runtime.

```powershell
cd api
$env:DOTNET_ROLL_FORWARD = "LatestMajor" # only if .NET 9 is not installed locally
dotnet run --launch-profile http
```

In a second terminal:

```powershell
cd web
npm.cmd install
npm.cmd run dev
```

Copy `api/appsettings.Development.example.json` to `api/appsettings.Development.json` before entering real provider credentials. The normal local addresses are `http://localhost:5141` for the API and `http://127.0.0.1:5173` for the Vite app.

## Render configuration

`render.yaml` is prepared with the Framingham Motors public contact and pickup details:

- Showroom: 865 Waverly St, Framingham, MA 01701
- Phone: (508) 306-8170
- Email: sales@framinghammotors.com
- Transport pickup coordinates: 42.2738807, -71.4336963

The manifest deliberately keeps `Inventory__DatabasePath=/var/data/retrodrive.db` and the existing `inventory-data` disk name. This preserves the current SQLite inventory when an existing Render service is rebranded. Do not change those values unless you intentionally want a new, empty inventory database.

Set `Admin__Password`, `Close__ApiKey`, `Close__StatusId`, and `Cloudinary__CloudName` as private Render environment variables. `Admin__SessionSecret` is generated by Render.

All public copy is ready to change in Render under **Environment**. Change a value, save it, then redeploy the service:

- `SiteSettings__ShowroomAddress`, `SiteSettings__Phone`, `SiteSettings__Email`, and `SiteSettings__ShowroomHours` update the header, footer, About contact card, and maps.
- `SiteSettings__FooterDescription`, `SiteSettings__FooterHoursTitle`, `SiteSettings__FooterOperationsTitle`, `SiteSettings__FooterVipTitle`, and `SiteSettings__FooterVipDescription` update the B&B-style footer.
- `Shipping__PickupAddress`, `Shipping__PickupLatitude`, and `Shipping__PickupLongitude` update the transport pickup point and route map.
- `TrustedNetwork__ContentJson` updates the home-page metrics, approach block, credentials, and B&B partner icons. Partner `image` values are public paths such as `/partners/ally.svg`.
- `About__ContentJson` updates the entire About page, including its headline, story, contact labels, and hours.
- `Legal__ContentJson` updates Privacy Policy, Terms of Service, and Purchase Terms. It contains `privacy`, `terms`, and `returns` objects, each with `title`, `updated`, and `sections`.

## Operational notes

- The `/admin` workspace requires the Render admin credentials and publishes vehicles to the SQLite inventory.
- Vehicle photos use Cloudinary public IDs. If Cloudinary is not configured, the seeded sample listings safely use fallback images for local demonstration.
- Lead forms call the API only; provider credentials are never sent to the browser.
